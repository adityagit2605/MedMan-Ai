# Healthcare Appointment Manager - Phase 1

This repository contains the phase 1 skeleton for the Healthcare Appointment & Follow-up Manager.

## Stack
- Frontend: React + Tailwind CSS
- Backend: Java Spring Boot + PostgreSQL + Redis
- LLM Service: Python FastAPI

## Structure
- `frontend/`: React Vite application
- `backend/`: Spring Boot Java application
- `llm-service/`: FastAPI python application for LLM integration
